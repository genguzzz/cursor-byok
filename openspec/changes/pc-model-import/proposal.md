# PC 模型快速导入与价格倍率

## 背景

当前 `cursor-byok` 的模型配置需要逐个通过桌面 API 创建。PC 端点模型列表可以变化，且显示名需要包含相对官方费率的倍率，后续手工导入容易漏模型或使用过期价格。

## 目标

- 在当前仓库提供可重复运行的 `pc-model-import` skill。
- 从 OpenAI 兼容端点的 `/models` 自动发现模型。
- 以 `gpt-5.6-luna` 为 `1.00x`，使用官方标准短上下文价格计算输入+输出各 1M token 的相对倍率。
- 将倍率写入模型显示名，保持 `PC` 分组，并把 PC 组排在最前面。
- 对官方价格表没有收录的模型明确显示 `x?`，不猜测价格。

## 非目标

- 不修改 Cursor BYOK 的数据库 schema。
- 不删除端点已经下线的旧模型。
- 不把中转站余额、折扣或内部扣费误认为 OpenAI 官方价格。
